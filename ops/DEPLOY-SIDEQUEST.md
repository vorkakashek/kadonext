# Ручная публикация SIDEQUEST

Подготовлена общая сборка текущего сайта KADO: она включает SIDEQUEST и остальные
изменения рабочей копии, публикацию которых подтвердил автор. Интерактив находится
внутри статического релиза; отдельный сервер для него не нужен.

Для публикации новых изменений выполнить в PowerShell:

```powershell
Set-Location 'E:\GitHub\kadoflow'
npm run deploy -- -SkipBuild
```

`-SkipBuild` использует уже подготовленную и проверенную `.output/public`.
Скрипт проверит комплектность SIDEQUEST, упакует релиз, загрузит его по SSH,
проверит nginx и переключит релиз атомарно. Проверки русской и английской страниц
кейса и интерактива выполняются до отключения автоматического отката.

Если после подготовки менялись исходники, сначала выполнить `npm run build`
или запустить `npm run deploy` без `-SkipBuild` для сборки перед публикацией.

Публичные адреса после успешной выкладки:

- https://kadonext.com/ru/projects/sidequest/
- https://kadonext.com/ru/projects/sidequest/interactive/
- https://kadonext.com/en/projects/sidequest/
- https://kadonext.com/en/projects/sidequest/interactive/

При ошибке SSH релиз не активируется. При ошибке серверных проверок после
переключения скрипт возвращает прежний релиз и конфигурацию nginx.

Сведения о замене изображений и видео: `content/sidequest-media.md`.

## Если выкладка остановилась из-за истёкшего сертификата

Из PowerShell на компьютере с рабочим SSH-доступом:

```powershell
powershell -ExecutionPolicy Bypass -File "E:\GitHub\kadoflow\scripts\repair-production-tls.ps1" -Deploy
```

Команда подключается тем же ключом, продлевает существующий сертификат
`kadonext.com` через Certbot, проверяет конфигурацию и перезагружает nginx.
После строгих HTTPS-проверок локального nginx и шрифта она запускает публикацию
подготовленной сборки с `-SkipBuild`. При ошибке любого шага публикация не начинается.
Без `-Deploy` выполняются только восстановление и проверки HTTPS.

## Раздача ресурсов с VPS

24 ноября 2026 опубликованный релиз перенесён на VPS без изменения контента.
Активирован `/var/www/kadonext/releases/vps-20261124124459`; исходный релиз
`20261121133449-353a5be` сохранён. В новом релизе все Nuxt-файлы находятся под
`/_nuxt/vps-20261124124459/`, чтобы не менять содержимое старых immutable URL.
Сжатые `.br` и `.gz` обновлены вместе с HTML и JS. Проверены 43 HTML-страницы
и 681 связанный ресурс/Nuxt-файл по HTTPS. Контактный API и защита аналитики работают.

CDN удалён. Обычные `npm run build` и `npm run deploy` используют основной домен
для JS, CSS, шрифтов, изображений и видео. Возврат к прежнему CDN не предусмотрен.
`npm run origin:check` проверяет готовую сборку; деплой повторяет эту проверку.

`deploy-origin-only.ps1` сохранён как совместимая команда обычной сборки и деплоя.
Ключ `-BuildOnly` собирает сайт без публикации.

Одноразовая миграция выполнена через `ops/migrate-production-origin.sh` и
`scripts/migrate-static-origin.mjs`: они копируют активный релиз, меняют только
адреса доставки ресурсов и переключают симлинк после проверки. Для следующих
публикаций нужен обычный `npm run deploy`.
